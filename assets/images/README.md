# 채피움 홈 이미지

제공된 브랜드 보드의 노을·산자락·집짓기 분위기를 바탕으로 새로 생성한 브랜드 이미지입니다. 사용자 집 사진이나 실제 공사 현장 기록이 아닙니다.

- `home-sunset.png`: 데스크톱 홈 대표 이미지.
- `home-sunset-mobile.png`: 같은 건축 분위기를 모바일 세로 화면에 맞춘 이미지.

사진 안에 로고·문구를 합성하지 않고, HTML 텍스트와 기존 채피움 로고 자산을 별도로 표시합니다. 기록 데이터와 첨부파일은 기존 IndexedDB에 보관하며 이 이미지로 교체하지 않습니다.

## 플랫폼 1차 버전

`home-daylight.webp`는 사용자가 제공한 밝은 주택 중심 디자인을 참고해 새로 생성한 브랜드 이미지입니다. 원본 생성 PNG를 유지하고, 배포용 파일은 WebP 품질 88로 압축했습니다. 사용자 집의 실제 사진으로 표시하지 않습니다.
