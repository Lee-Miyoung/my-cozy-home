기본색은 딥플럼 `#3B0F3F`, 아이보리 `#FAF7F4`, 베이지 `#DCC5AB`입니다. 베이지는 배경·테두리에 사용하며, 일반 텍스트에는 대비가 충분한 어두운 색상을 사용합니다.

모든 리소스와 매니페스트 경로는 상대 경로이므로 GitHub Pages의 `/my-cozy-home/` 하위 경로에서 사용할 수 있습니다. 매니페스트와 아이콘은 홈 화면 표시용이며, 서비스 워커·오프라인 캐싱·앱스토어 패키징은 구현하지 않았습니다.

IndexedDB 이름 `house_time_private_v1`, 버전 1, 저장소 `meta`/`attachments`, 백업 식별자 `house-time`과 버전 1은 기존 그대로 유지합니다. 브랜드 변경은 개인 기록을 초기화하거나 서버로 전송하지 않습니다. 다른 주소·브라우저로 이동하면 기존 로컬 기록이 보이지 않으므로 기존 주소에서 ‘설정·백업 → 전체 데이터 백업’을 실행한 뒤 새 주소에서 JSON을 복원하세요. 사용자 개인 백업 파일은 이 공개 저장소에 올리지 마세요.

자재 플랫폼·전문가 연결·커뮤니티는 준비중입니다. 로그인·기기 간 동기화·서버 저장은 제공하지 않습니다.
