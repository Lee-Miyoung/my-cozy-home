## 남은 사항

공개 소개 화면의 기존 320px 가로 넘침은 홈 대시보드 작업 범위 밖이므로 별도 수정이 필요합니다. 사용자의 기기에만 있는 실제 IndexedDB 데이터는 직접 열람하지 않았으며, 데이터 보존은 합성 기존 버전 데이터와 백업·복원 회귀로 검증했습니다.
