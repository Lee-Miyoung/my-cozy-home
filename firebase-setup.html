채피움 · 삼남매 가족 공유 연결

한 번만 Firebase 보안 규칙을 게시하면 기존 ‘엄마의 뜰’ 프로젝트를 삼남매가 공동으로 사용하도록 연결할 수 있어요.

  1. 아래 보안 규칙 복사를 누르세요.
  2. Firebase 콘솔 열기 → Realtime Database → 규칙으로 이동하세요.
  3. 기존 내용 전체를 선택해 새 규칙으로 교체하고 게시하세요.
  4. 채피움에 돌아와 구글 로그인 → 관리자의 ‘엄마의 뜰 가족 공유 시작’을 한 번 누르세요.

개인 사진·건축비·서류는 공개 GitHub에 저장하지 않습니다. Firebase 데이터 접근은 등록된 삼남매 계정으로 제한됩니다. 규칙을 게시하기 전에 기존 개인 기록의 백업을 권장합니다.
