# 채피움 CHAEPIUM

**집을 짓는 모든 순간을, 채피움에.**

모든 건축주를 위한 집짓기 기록 플랫폼의 1차 로컬 저장 버전입니다. 공개 소개 화면과 실제 프로젝트 대시보드를 분리하며, 일정·예산·사진일기·서류·자재·연락처를 프로젝트별로 관리합니다.

공개 주소: https://lee-miyoung.github.io/my-cozy-home/

## 실행

별도 빌드나 패키지 설치 없이 정적 서버에서 실행합니다.

```sh
python3 -m http.server 8000
```

브라우저에서 서버의 주소를 엽니다. 파일을 직접 여는 대신 HTTP 서버를 사용하세요. GitHub Pages `/my-cozy-home/` 하위 경로도 지원합니다.

- `index.html`: 앱 셸, 공식 로고·아이콘·매니페스트 연결.
- `assets/app.js`: UI, 프로젝트 관리, IndexedDB, 백업·복원.
- `assets/brand/brand.css`: 공통 요소·공식 브랜드·로컬 폰트.
- `assets/platform.css`: 공개 홈페이지와 각 관리 화면의 반응형 디자인.
- `assets/fonts/`: 자체 호스팅 폰트 및 OFL 라이선스.

## 실제 제공하는 기능

- 프로젝트 생성·정보 수정·전환·삭제, 대표 사진, 면적·유형·예산·목표일.
- 단계 추가·숨기기·수정, 일정·담당자·파일, 할 일 추가·수정·삭제·완료.
- 견적·계약·실제 지급을 구분한 비용, 지급 구분, 영수증, 분류·월별 합계.
- 사진 여러 장, 작업 내용·현장 특이사항·결정·메모, 월·단계별 필터, 확대·수정·삭제.
- 서류의 분류·날짜·검색·이름 변경·첨부·미리보기/다운로드·삭제.
- 자재의 공간·브랜드·규격·가격·후보/확정·비교 메모·선택 이유.
- 연락처, 입주 이후 관리 일정, 모든 프로젝트와 첨부파일의 전체 백업·복원.

신규 방문 시 예시 프로젝트를 실제 데이터에 넣지 않습니다. 새 프로젝트 생성 시 한국 건축주가 참고할 수 있는 기본 단계·체크리스트가 생성됩니다. 지역과 건축 조건에 따라 절차가 다르므로 법적 필수 절차를 대체하지 않습니다.

자재 탐색·비교, 전문가 연결, 건축 사례 탐색, 건축주 커뮤니티는 **준비중**입니다. 인증·클라우드 저장·기기 간 동기화·사진 비교는 구현하지 않았으며 작동하는 기능처럼 표시하지 않습니다.

## 데이터 보존과 백업

IndexedDB 이름과 버전은 기존 `house_time_private_v1`, 버전 `1`을 유지합니다. `meta`, `attachments` 저장소를 그대로 사용합니다.

- 기존 단일 프로젝트의 `meta.state`가 있으면 데이터를 변경하지 않고 독립 프로젝트로 등록합니다. 원본 메타데이터는 `meta['legacy-original-v1']`에 보존하며, 기존 첨부파일 ID와 Blob은 유지합니다. 이 사본은 외부 전체 백업을 대신하지 않습니다.
- 프로젝트 목록은 `meta.workspace`, 개별 상태는 `meta['project:'+id]`에 저장합니다. `meta.state`에는 현재 프로젝트를 함께 유지합니다.
- 프로젝트 저장은 버전 충돌 검사와 첨부파일 존재 검사를 포함한 트랜잭션으로 처리합니다. 오래된 탭의 저장은 최신 기록을 덮어쓰지 않고 거부하며, 새로고침을 안내합니다. 이전 버전 탭이 뒤늦게 저장한 기록은 다음 로딩 때 별도 프로젝트로 보존합니다. 사진·문서 등은 서버로 업로드하지 않고 IndexedDB Blob으로 보관합니다.
- 전체 JSON 백업은 `app: house-time`, `version: 2`이며 모든 프로젝트와 참조된 파일을 포함합니다. 이전 `version: 1` 단일 프로젝트 백업도 가져올 수 있습니다.
- 복원은 내용·식별자·금액·첨부 누락을 먼저 검사한 뒤 하나의 트랜잭션으로 적용합니다. 복원 전 상태와 파일은 `meta['recovery:last']`에 보존하며 설정 화면에서 내려받을 수 있습니다. 저장 공간 부족 등으로 트랜잭션이 실패하면 기존 데이터가 유지됩니다. 기존 저장소에 파일이 이미 누락된 경우에도 정상 백업으로 복원할 수 있습니다. 이때 복원 전 사본은 누락 목록을 포함한 점검용 형식(`house-time-recovery`)이며, 일반 복원용 백업과 명확하게 구분합니다.
- 기록 삭제나 파일 교체 시 다른 프로젝트가 참조하는 파일은 삭제하지 않습니다. 저장에 실패하여 남은 미사용 파일은 설정에서 정리할 수 있습니다.

기록은 브라우저·프로필·접속 origin에 종속됩니다. 기기나 브라우저를 변경하거나 브라우저 데이터를 지우기 전에 **설정·백업 → 전체 백업**을 사용하세요. 개인 사진·서류·JSON 백업을 공개 저장소에 커밋하지 마세요.

새 프로젝트 생성은 한 브라우저에서 100개까지, 첨부파일은 개당 30MB, 전체 JSON 백업·복원은 파일당 250MB까지 지원합니다. 이전 탭의 기록 보존을 위해 자동 복구된 프로젝트는 추가될 수 있습니다. 일부 사진은 최대 1800px로 자동 축소합니다. 실제 저장 한도는 브라우저에 따라 다릅니다. PNG/ICO 브랜드 원본은 재생성하지 않고 제공된 파일을 사용합니다.

## 디자인과 검증

선택된 06번 캘리그래피 자산을 공식 로고로 유지합니다. 폰트는 Pretendard와 Noto Serif KR 기반의 Chaepium Editorial이며, 원본·변환 및 라이선스는 `assets/fonts/README.md`를 참고하세요. 브랜드용 건축 이미지는 생성 이미지이며 실제 사용자 집 사진으로 표시하지 않습니다. 새로 제작한 주간 건축 이미지는 WebP 약 250KB로 제공하고 기존 사진을 덮어쓰지 않습니다.

브라우저 회귀 테스트:

```sh
python3 -m pip install playwright
python3 -m playwright install chromium
CHAEPIUM_TEST_URL=http://127.0.0.1:8000/ python3 tests/platform-smoke.py
```

이미 실행 중인 Chromium CDP를 쓰려면 `CDP_URL=http://127.0.0.1:9222`를 설정합니다. 시스템 Chromium은 `CHROMIUM_PATH`로 지정할 수 있습니다. 결과물은 기본적으로 임시 폴더에 생성하며 `CHAEPIUM_TEST_ARTIFACTS`로 변경할 수 있습니다. 테스트는 독립 브라우저 컨텍스트와 합성 자료만 사용합니다.

검증 범위는 신규 설치·기존 데이터 이전, 프로젝트·기록 CRUD, 첨부파일, 예산 계산, v1/v2 백업·복원·잘못된 파일 거부, 12개 화면의 320–1440px 반응형, 뒤로가기·빠른 추가·콘솔 오류, 탭 충돌과 이전 버전 탭의 뒤늦은 저장 보존입니다. 실제 iPhone Safari와 네이티브 Android 기기 검증은 별도입니다. 매니페스트·아이콘은 제공하지만 서비스 워커 기반 오프라인 앱 셸과 서버 동기화는 제공하지 않습니다.
